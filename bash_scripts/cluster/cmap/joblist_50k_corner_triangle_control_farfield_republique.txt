# republique (AVX2, 16 cores -> 4 jobs x 4 threads), after joblist_50k_penalty_and_smoothing_corner_sampling_farfield.txt

# profile E_theta', seeds 0-4.
#
# WHY. The corner sampler of the runs E and E_theta' of 2026-10-13 (wave 1 of
# joblist_50k_corner_sampling_and_validation_selection_farfield_republique.txt) draws its corner component in the
# similarity coordinates (xi uniform on [0, 5], tau log-uniform on [1e-6, 1]). This control keeps the corner
# fraction 0.5 and the importance weighting, and replaces that component by the uniform law on the ell^1 triangle
# {(s-B)+(T-t) <= 0.1}, density 2/delta^2 with delta = 0.1, which carries no information on the similarity
# variable (learning_option_pricing/pricing/corner_triangle_sampling.py). Weights w = u/m with
# m = 0.5 u + 0.5 (2/delta^2) 1_triangle: 2 outside the triangle, 4.16e-3 inside (unbiasedness checked by
# test/pricing/test_corner_triangle_sampling.py). The comparison with E_theta' corner separates the effect of
# concentrating the points at the corner from that of distributing them along xi.
# Protocol of 2026-10-13, unchanged otherwise: same backbone and g_theta' (model_init and similarity_profile_init
# seeds of the master seed), Adam lr 1e-2 with the two-stage decay, 50000 iterations, n_f = 4096, far-field
# Dirichlet condition, Black-Scholes terminal profile, radii (0.1, 0.3), --best-state-selection validation on the
# fixed set drawn from the SIMILARITY-variable mixture (seed derive_seed(seed, "validation_set"): the same set
# as E and E_theta' at each seed; checked on a 200-iteration debug run, seed 941185844 for seed 1 in both laws),
# model snapshot every 1000 iterations, so the state can also be selected again on the common set of
# derive_seed(0, "validation_set") by compare_corner_treatments_on_fixed_validation_set.py.
