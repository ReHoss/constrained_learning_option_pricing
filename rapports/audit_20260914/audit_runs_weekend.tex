\section{Géométrie de l'exclusion}
\label{sec:exclusion}

\paragraph{Code.} L'exclusion est implémentée dans \code{pilot.py},
fonction \code{sample\_collocation} (lignes 183--234). La condition codée,
ligne 219, est
\begin{center}
\code{inside\_corner = (s\_raw - B) + (T - t\_raw) <= corner\_exclusion\_window}
\end{center}
appliquée aux tirages uniformes \code{s\_raw} $\sim\mathcal U(B,s_\infty)$ et
\code{t\_raw} $\sim\mathcal U(0,T)$ (lignes 214--215) ; les points retenus par
la condition sont retirés puis \emph{redessinés} (lignes 223--224), au plus
\codepath{_CORNER_REJECTION_MAX_PASSES} $=50$ passes (ligne 102). La valeur
de la fenêtre est fixée ligne 1173 :
\code{corner\_window = args.corner\_window if ... else max(args.epsilons)}, soit
$w=0.1$ pour tous les runs audités (\code{corner\_window: 0.1} dans chaque
\code{metadata.yaml}). L'exclusion n'est active que sous
\codepath{--exclude-corner-from-collocation} (ligne 1372 :
\code{corner\_exclusion\_window=(corner\_window if args.exclude\_corner\_from\_collocation else None)}).
Le masque d'évaluation (\codepath{evaluate_against_closed_form}, ligne 696) est
\code{corner\_mask = (ss - B).abs() + (T - tt) <= corner\_window}, identique à
la condition d'échantillonnage puisque $s>B$ sur la grille.

\paragraph{Géométrie.} \etabli\ La région exclue est
\[
N_w=\{(s,t)\in(B,s_\infty)\times(0,T):\ (s-B)+(T-t)\le w\},\qquad w=0.1,
\]
le triangle rectangle de sommets $(B,T)$, $(B+w,T)$ et $(B,T-w)$. Elle est
\textbf{bornée en temps} : $(s,t)\in N_w$ impose $T-t\le w-(s-B)\le w$, donc
$t\in[T-w,T]=[0.9,1]$. Ce n'est \textbf{pas} une bande en $s$ valable pour
tout $t$ : un point de la couche $[B,B+\epscoin]$ avec $\tau>w-(s-B)$ est
échantillonné et le résidu y est imposé.

\paragraph{Aires.} \etabli\ $|N_w|=w^2/2=5\times10^{-3}$ ;
$|(B,s_\infty)\times(0,T)|=(s_\infty-B)\,T=2.4$ ; fraction exclue du domaine
$=5\times10^{-3}/2.4=2.083\times10^{-3}$, soit $0.208$ pour cent.
\mesure\ Sur la grille d'évaluation du pilote ($300\times100$, $s$ de
$B+10^{-4}$ à $s_\infty$, $t$ de $0$ à $T-10^{-4}$) la fraction de noeuds
dans $N_w$ vaut \codepath{corner_window_grid_fraction} $=2.433\times10^{-3}$
(\code{summary\_eps0.1.yaml} de chaque run 50k), l'écart avec la valeur
continue provenant de la discrétisation (le triangle touche deux bords de la
grille). Bande $[B,B+\epscoin]\times[0,T]$ : aire $\epscoin T=0.1$ ; fraction
de la bande recouverte par $N_w$ : $5\times10^{-3}/0.1=5$ pour cent. Les
$95$ pour cent restants de la bande sont échantillonnés.

\section{Métriques du rapport \code{strike\_g2}}
\label{sec:metriques}

\paragraph{Métriques du rapport.} Le rapport
\codepath{rapports/strike_g2/strike_g2.tex} (daté du 1\up{er} septembre 2026)
utilise deux quantités au strike $s=K=1$.

\begin{enumerate}
\item \etabli\ (\S5 du rapport, table « Valeurs exactes du Gamma en $s=K$ »)
  La dérivée seconde en $s$ du facteur non trivial de $g_2$ \emph{seul}, en
  forme close, sans réseau, à $t\in\{0,0.2,0.3,0.5,0.7,0.8,0.9,0.95,0.99,0.999\}$,
  contre $\partial_{ss}\VDO(K,t)$ (\codepath{reiner_rubinstein_down_and_out_put_gamma},
  \codepath{learning_option_pricing/pricing/barrier.py}). Code :
  \codepath{compare_payoff_modes_at_strike.py}, \codepath{render_exact_gamma_at_strike_table}
  (ligne 930).
\item \mesure\ (\S5, « Score global ») La courbure ponctuelle du prix appris
  complet, $\partial_{ss}\Phi_\theta(K,t)$, par différence seconde centrée de
  pas $h=10^{-4}$ en double précision sur le modèle entraîné gelé
  (\codepath{_pointwise_second_difference}, lignes 473--484 :
  $(\Phi_\theta(K+h,t)-2\Phi_\theta(K,t)+\Phi_\theta(K-h,t))/h^2$), pour $t$
  sur la grille \code{torch.linspace(0.0, T - 1e-4, 60)} (ligne 1604), contre
  $\partial_{ss}\VDO(K,t)$ ; score
  $\mathrm{MAE}=\frac1{60}\sum_{t}\big|\partial_{ss}\Phi_\theta(K,t)-\partial_{ss}\VDO(K,t)\big|$
  (\codepath{render_mean_abs_error_summary}, lignes 691--707, avec
  \code{t\_max = T - 1e-4}). Le rapport écrit cette quantité
  « MAE $|\Phi_\theta(K,t)-\partial_{ss}\VDO(K,t)|$ sur $t\in[0,1)$ » (lignes
  250--251 du \code{.tex}) : le symbole $\Phi_\theta$ y désigne en fait
  $\partial_{ss}\Phi_\theta$ (le code ne compare que des dérivées secondes),
  et l'intervalle est la grille de $60$ points ci-dessus, dont le dernier
  point est $t=T-10^{-4}$.
\end{enumerate}

\paragraph{Fenêtre d'exclusion.} \etabli\ La fenêtre $N_w$ n'intervient
dans aucune des deux métriques : elles sont ponctuelles en $s=K$, où
$\zeta((K-B)/\epscoin)=\zeta(4)=1$ exactement. La seule exclusion présente
dans ce script est celle de l'analyse 1 (erreur $L^2$ relative globale contre
la même erreur restreinte à \code{ss >= B + margin}, ligne 224, marge $0.1$) :
une \emph{bande en $s$ pour tout $t$}, distincte du triangle $N_w$ de la
section~\ref{sec:exclusion}. Les runs du rapport n'excluaient rien à
l'entraînement (pas de clé \codepath{corner_exclusion_window} dans leur
\code{metadata.yaml}, drapeau inexistant dans le code de l'époque, cf.
section~\ref{sec:differences}).

\section{Erreurs avérées}
\label{sec:erreurs}

\subsection*{(a) Bugs de calcul}

\begin{enumerate}
\item \textbf{Plancher $\tau\ge10^{-8}$ dans la trace terminale du mode
  Black-Scholes.} \codepath{learning_option_pricing/pricing/terminal.py} : la
  constante \code{\_TAU\_EPS = 1e-8} (ligne 26) est appliquée par
  \code{\_d\_tilde\_1} / \code{\_d\_tilde\_2} (lignes 131, 139 à
  \code{66ee604\string^}), si bien que \code{black\_scholes\_put} évaluait à
  $t=T$ le prix $V^e(s,10^{-8})$ et non $(K-s)^+$. \mesure\ Écart maximal
  $1.197\times10^{-5}$ en $s=K$, égal à la valeur temps à la monnaie
  $K\sigma\sqrt{10^{-8}}/\sqrt{2\pi}=1.1968\times10^{-5}$ ; nul à la précision
  flottante loin de $K$. Résultats affectés : la ligne « Black-Scholes (deux
  routes) : trace terminale $1.071\times10^{-4}$, exacte à $10^{-5}$ près » de
  \codepath{rapports/selection_g2_strike/selection_g2_strike.tex}
  (\S« La condition terminale ») ; la métrique du rapport \code{strike\_g2}
  n'est pas affectée (sa grille s'arrête à $t=T-10^{-4}$, où le plancher est
  inerte). Conclusion des rapports inchangée (l'écart est trois à quatre
  ordres de grandeur sous les erreurs comparées). Le clamp s'activait sans
  journalisation, contrairement à la règle du projet. État à \code{HEAD} :
  corrigé par \code{66ee604} (payoff exact en $\tau=0$, activation journalisée).
\item \textbf{Drapeau \code{-{}-analytic-residual} inerte avant le
  11 septembre.} \code{pilot.py} lignes 271--277 (\code{HEAD}, introduites par
  \code{4a0af78}) : le choix de route testait
  \code{isinstance(g2, SplitSemigroupCornerExtension)}, de sorte que
  \codepath{BlackScholesCornerExtension} passait par la route ordinaire et que le
  drapeau était sans effet ; le commentaire rapporte une vérification (« loss
  identique à 5 chiffres significatifs sur 300 itérations avec et sans »). Le
  code antérieur n'étant dans aucun commit, cette vérification n'est pas
  reproductible ici. Résultats affectés : le run
  \codepath{20260907_194310_iters20000_eps0.1_seed0_blackscholes_analyticres}
  (\code{analytic\_residual: true} dans \code{metadata.yaml}, entraîné le
  7 septembre, donc avec le code d'avant \code{4a0af78} ; aucune ligne
  « interior residual route » dans son \code{training.log}), qui est la ligne
  « Black-Scholes (ORACLE), two-term residual » du rapport de sélection et sa
  « configuration retenue » (\S Reproductibilité). Ce run a été entraîné par
  la route ordinaire. Les runs du week-end ne sont pas affectés (route
  effective loguée depuis \code{0763373} :
  \code{BlackScholesCornerExtension ... two-term analytic}). Voir (c)~1 pour la
  conclusion.
\item \textbf{Lanceur \code{run\_joblist.sh} : un job en échec supprime la
  ligne de fin.} \codepath{bash_scripts/cluster/cmap/run_joblist.sh} ligne 11
  (\code{set -euo pipefail}) : lorsqu'un job sort avec un code non nul
  (\code{Illegal instruction}, journaux
  \codepath{launch_50k_migration_chapelle.log} et
  \codepath{launch_50k_migration_pouchet.log}), \code{xargs} renvoie un code
  non nul et le script s'arrête avant \code{echo "ALL JOBS FINISHED"}, ce qui
